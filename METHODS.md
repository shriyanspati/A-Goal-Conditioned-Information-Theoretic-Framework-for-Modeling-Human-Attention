# Methods

## Study Design

This project combines:

- theoretical framework development
- secondary quantitative analysis


## Dataset

The empirical demonstration uses a public Stroop dataset containing 131 participants.


## Statistical Analysis

Classical analysis:

- paired samples t-test
- Cohen's dz effect size


Information analysis:

- mutual information estimation
- Miller-Madow bias correction
- bootstrap confidence intervals


## Reproducibility

All analysis decisions should be specified before computation, including:

- relevance definitions
- binning strategy
- validation metrics
- statistical tests
